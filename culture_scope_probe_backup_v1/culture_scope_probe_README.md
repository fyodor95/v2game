# Эксперимент: динамические сравнения культуры в Victoria II

Цель — проверить поведение **оригинальной Victoria II HoD 3.04**, а не Project Alice. Пока правильность `is_accepted_culture = THIS` для нашей задачи не установлена. Корки в этом эксперименте служат диагностическими отметками.

## Запуск

1. Полностью перезапустить игру после установки файла `events/zz_culture_scope_probe.txt`.
2. Начать **новую тестовую партию за Пруссию (PRU), 1836 год**, предпочтительно без модов. Не использовать ценное сохранение. Для Chronology файл должен наследоваться из базовой папки: его `.mod` не содержит `replace_path = "events"`.
3. Поставить паузу. Открыть консоль клавишей `~` (обычно клавиша Ё; на некоторых раскладках Alt+21 на цифровом блоке).
4. Выполнить `event 3999900` и нажать единственную кнопку появившегося события. Событие меняет состояние только после выбора кнопки.
5. Пропустить один игровой день и снова поставить паузу: нужно обновление демографических показателей.
6. Проверить исходные данные в окнах провинций. Если они не соответствуют таблице, **не интерпретировать результат сравнений**: сначала сообщить о неудачной подготовке. Консольная команда `provid` помогает увидеть ID провинций при наведении.

| ID | Провинция | Владелец после подготовки | Ожидаемая культура населения |
|---|---|---|---|
| 301 | Canterbury / Кентербери | ENG | North German / северогерманская |
| 302 | Brighton / Брайтон | ENG | South German / южногерманская |
| 303 | Southampton / Саутгемптон | ENG | British / британская |

Подготовка временно передаёт эти три провинции Пруссии и применяет `assimilate = yes` при разных основных культурах, затем возвращает их Англии. Ожидается 100% заданной культуры в каждой провинции. Остальные провинции не ассимилируются. Пруссии задаются основная северогерманская и признанная южногерманская культуры. Англия имеет основную британскую и не признаёт обе немецкие культуры. Другие признанные культуры стран не удаляются и на выбранные три культуры не влияют.

## Три измерения

Все команды вводить, играя за PRU. При необходимости сначала выполнить `tag PRU`. Не добавлять ID провинции к командам: события страновые. События вызываются непосредственно из консоли, поэтому MTTH и случайности нет. Проверяемые условия находятся в `limit` эффектов: консольный обход `trigger` не обходит эти проверки. Статус великой державы и технология намеренно не проверяются — эксперимент изолирует семантику культуры.

**Фаза A, исходное состояние:** выполнить `event 3999901`, нажать кнопку и осмотреть корки в трёх провинциях. Если открыто окно провинции, закрыть и открыть его для обновления.

**Фаза B, меняем только признание у владельца:** выполнить `event 3999902`, нажать кнопку. Англия теперь признаёт северогерманскую культуру. Пропустить один день, поставить паузу, выполнить `event 3999901`, нажать кнопку и записать результат.

**Фаза C, меняем культуры претендента:** выполнить `event 3999903`, нажать кнопку. Основная культура Пруссии теперь южногерманская, признанная — северогерманская. Англия снова не признаёт обе немецкие культуры. Пропустить один день, поставить паузу, выполнить `event 3999901`, нажать кнопку и записать результат. Культуры населения провинций должны оставаться такими же, как после подготовки.

Каждое измерение сначала удаляет свои четыре вида диагностических корок и выставляет их заново. Существующие английские и любые другие корки не учитывать. Навести курсор на флаг в списке национальных территорий, чтобы определить страну.

| Диагностическая корка | Проверяемое условие | Фаза A: нужный результат | Фаза B: нужный результат | Фаза C: нужный результат |
|---|---|---|---|---|
| PRU — Пруссия | `is_primary_culture = THIS` | 301 | 301 | 302 |
| FRA — Франция | `is_accepted_culture = THIS` | 302 | 302 | 301 |
| BAV — Бавария, контроль владельца | `is_primary_culture = yes` | 303 | 303 | 303 |
| SAX — Саксония, контроль владельца | `is_accepted_culture = yes` | нигде | 301 | нигде |

В таблице предполагается, что `accepted` обозначает отдельно признанные культуры. Если команда также включает основную культуру, FRA может отмечать одновременно 301 и 302 — это тоже подходит для исходного правила `primary OR accepted`, если 303 не отмечается и результат не зависит от признания культур Англией. Аналогичное включение основной культуры в контроль `accepted = yes` добавит SAX на 303; записать это отдельно.

## Как понимать результат

- PRU переходит с 301 на 302 после фазы C: сравнение с основной культурой динамическое и использует текущую культуру Пруссии.
- FRA следует крупнейшей культуре провинции и текущим признанным культурам Пруссии, не меняясь из-за фазы B: кандидат для линейной серии подтверждается на этих случаях.
- FRA отсутствует в фазах A/C, но появляется **на всех трёх провинциях в B**: сравнение обратное нужному. Именно такой результат следует из исследованной реализации Project Alice; это гипотеза для проверки, а не установленный факт об оригинальной игре.
- FRA повторяет контроль SAX: возможна интерпретация `THIS` как булева значения или сравнение с владельцем; нужная семантика не подтверждена.
- Неверные или отсутствующие контрольные отметки требуют сначала проверки подготовки, версии игры, страны получателя и загрузки файла.

**Дополнительная проверка реальной выдачи корок:** после записи результатов любой фазы выполнить `event 3999904` и нажать кнопку. Он убирает диагностические отметки и применяет именно `primary = THIS OR accepted = THIS` с `add_core = THIS`. Требуемый результат: прусские корки на 301 и 302, но не на 303. Особенно полезно проверить в фазе B: обратное сравнение ошибочно выдаст корку и на британский Саутгемптон. `event 3999901` заново восстановит четыре диагностических слоя.

Положительный результат на однокультурных провинциях ещё не заменяет тест крупнейшей культуры при распределении 40/35/25 и естественного `trigger` будущего события. Эти проверки нужны перед включением генератора; сейчас проверяется ключевой спорный оператор.

## Что прислать

Версию игры, название активного мода (или отсутствие мода), подтверждение культур/владельцев после подготовки и по каждой фазе списки ID с PRU/FRA/BAV/SAX-корками. Например: `A: PRU=301; FRA=302; BAV=303; SAX=нет`. Для 3999904 — отдельно список провинций с прусской коркой и фазу проверки.

## Повторение и удаление

`event 3999900` повторно задаёт исходное состояние выбранных культур и провинций, после чего можно повторить A/B/C. Это сброс тестовой установки, **не восстановление исходной партии**. Для возврата к обычной игре выйти из тестовой партии и начать новую либо загрузить сохранение, сделанное до эксперимента.

Удаление установленного `events/zz_culture_scope_probe.txt` и перезапуск игры полностью убирают тестовые события. Само удаление файла не откатывает изменения тестового сохранения. Файл инструкции `culture_scope_probe_README.md` можно также удалить. Существующие файлы игры экспериментом не заменяются.
