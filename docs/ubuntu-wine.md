# Victoria II на Ubuntu через Wine

Вариант запуска для Ubuntu 22.04 x86_64 с Wine 10.0 и 32-битными библиотеками OpenGL. Скрипт запускает оригинальный `v2game.exe` с CreatineCore из этой сборки.

## Первый запуск

Нужны `wine`, `wineboot` и `wineserver` из сборки Wine с поддержкой 32-битного префикса (`WINEARCH=win32`). Если пакеты Wine ещё не установлены, для Ubuntu 22.04 можно установить `wine` и `wine32:i386` из репозитория Ubuntu после подключения архитектуры `i386`. При уже установленном Wine из WineHQ используйте его.

Для системы с Mesa установите зависимости:

```bash
sudo dpkg --add-architecture i386
sudo apt update
sudo apt install rsync cabextract libgl1:i386 libglx-mesa0:i386 libgl1-mesa-dri:i386
```

Из корня репозитория запустите:

```bash
bash tools/ubuntu-wine/run.sh
```

Первый запуск создаёт отдельный префикс и копирует игровые файлы. Скрипт извлекает `d3dx9_41.dll` из `dx/Mar2009_d3dx9_41_x86.cab` и указывает Wine загружать её и штатную DLL `dinput8.dll` этой сборки. При повторных запусках копия игровых файлов обновляется из текущего репозитория, а профиль сохраняется.

Для русских подписей на карте скрипт запускает Wine с локалью `ru_RU.UTF-8`, если она доступна. Это даёт игре кодовую страницу Windows-1251 при переводе названий в верхний регистр. Если скрипт сообщает, что локаль недоступна, выполните `sudo locale-gen ru_RU.UTF-8` и перезапустите игру.

## Пользовательский каталог и настройки

По умолчанию папка запуска находится в `~/.local/share/v2game/ubuntu-wine`. Если задан `XDG_DATA_HOME`, вместо `~/.local/share` используется его значение. Переменная `VIC2_WINE_DIR` задаёт полный путь к отдельной папке запуска, например `VIC2_WINE_DIR="$HOME/vic2-test" bash tools/ubuntu-wine/run.sh`.

Пользовательский каталог внутри папки запуска — `prefix/drive_c/v2game-userdata`. Скрипт выводит его полный путь при запуске. Внутри него находятся:

| Где | Что хранится |
| --- | --- |
| `save games/` | Ручные сохранения и автосохранения |
| `settings.txt` | Настройки, которые читает и сохраняет игра |
| `logs/`, `map/cache/`, `gfx/flags/` | Игровые журналы и кэш |

Скрипт создаёт пользовательский `settings.txt` при первом запуске из файла в корне репозитория и включает оконный режим. Настройки для последующих запусков меняйте в пользовательском `settings.txt` при закрытой игре. Файл `prefix/drive_c/v2game/userdir.txt` задаёт путь `C:/v2game-userdata/`.

Снимки по F11 игра пишет рядом с исполняемым файлом, в `prefix/drive_c/v2game/Screenshots/` внутри папки запуска.

Журнал Wine находится в `wine.log` в папке запуска. Журнал CreatineCore находится в `prefix/drive_c/v2game/z_CreatineCore/Logs/v2dll.log`.

При запуске исходной сборки на Windows без `userdir.txt` сохранения и настройки находятся в `%USERPROFILE%\Documents\Paradox Interactive\Victoria II` или в соответствующей папке «Документы», если она перенаправлена.
