# Ревью сгенерированных данных Chronology

Проверен окончательный набор из **1147 событий `CoreAddingEvents`**: 520 первых корок и 627 соседских распространений. Ошибок в сопоставлении с картой кандидатов, ссылках проверенных групп и локализации не выявлено. Ревью относится к сгенерированным данным и не заменяет [испытания настоящей игры](chronology-acceptance.md).

Источники сравнения: основной репозиторий `c0b8cac2009d03eb98896cf9cb05aa1408e294b8` до установки перегенерированных файлов; [импорт стран](chronology-country-import.md) в `48c509e349621cf5ba043126f99410b729146f8f`; окончательный autogen `5d15010982a49348642d025246a5294fe348d212`. Изменено 129 игровых и служебных файлов: 115 новых файлов решений, шесть файлов событий, шесть локализаций и два списка идентификаторов.

## Сохранение существующих механизмов

Сравнивались структуры разобранных скриптов и исходники соответствующих генераторов. Для сопоставления старых и новых событий исключены перенумерованные `id`, `title`, `desc` и ключи имён опций. В `after_union` из новой структуры дополнительно исключались только эффекты, адресованные новым тэгам; это позволяет проверить сохранность старых эффектов независимо от расширения списка стран. Реальные ссылки между событиями проверены отдельно без удаления идентификаторов.

| Файл | До | После | Результат |
| --- | ---: | ---: | --- |
| `after_union.txt` | 67 | 68 | Прежние условия и эффекты сохранены; добавлены новые малые страны |
| `change_tag.txt` | 576 | 806 | Прежние 576 событий сохранены, добавлены две стадии для каждой из 115 стран |
| `removing_cores.txt` | 237 | 352 | Прежние 237 событий сохранены, добавлено 115 |
| `super_nationalism.txt` | 265 | 380 | Прежние 265 событий сохранены, добавлено 115 |
| `adding_cores.txt` | 755 | 1147 | Первые 234 → 520; соседские 521 → 627 |

Единственное новое событие `after_union` относится к `RUS` с основной культурой `russian`: после импорта появились малые страны `DON`, `RSR`, `CLR`. Остальные расширения этой группы добавляют удаление корок новых стран при прежних ограничениях по юниону, владельцу и наличию национальной провинции. В `super_nationalism` юнионы по-прежнему исключены; условия освобождения, уменьшение `militancy` POP и выдача повода для войны не изменились.

Для всех 403 пар `change_tag` проверено, что первая стадия вызывает следующий правильный ID, а ответная стадия переключает игрока именно на тэг из первой стадии. Для 115 новых файлов `peaceful_settlement_TAG.txt` проверены полнота покрытия тэгов и побайтовое совпадение с существующим шаблоном `ABU` после замены тэга. Получено ровно 230 новых решений. Старые файлы мирных решений и общий обработчик `events/peaceful_settlement.txt` не изменены.

Полное сопоставление соседских пар подтвердило: ни одна прежняя пара «культура — нединамическая страна» не потеряна. Условия соседского распространения сохранены. Изменения первых корок — глобальное отсутствие корок, проверка основной культуры/юниона, повторение условий перед эффектом и нормировка MTTH — проверены отдельно [валидатором механики](chronology-core-events.md).

## MainCountry, D-тэги и setting_cores

Итоговая карта содержит 234 культуры и 107 назначений основного D-тэга. Число назначений может превышать 50: генератор циклически использует имеющийся пул D-тэгов, как и прежде. У каждой культуры есть хотя бы один кандидат первой корки; максимальное число кандидатов — 25. MTTH каждой первой пары равен `4*n`, соседской — 4.

Промежуточная версия с 1129 событиями оставляла девять культур без кандидата первой корки: их прежняя основная страна только признавала эту культуру. После уточнения пользователя таким культурам назначен основной D-тэг. Прежняя страна сохранена среди дополнительных кандидатов для соседского распространения:

| Культура | Прежний MainCountry | Итоговый основной D-тэг |
| --- | --- | --- |
| `basque` | SPA | D08 |
| `uighur` | XIN | D14 |
| `moluccan` | BAL | D24 |
| `afro_caribeno` | HAI | D16 |
| `kru` | LIB | D23 |
| `tiv` | SOK | D26 |
| `tuareg` | TRI | D27 |
| `oromo` | ETH | D45 |
| `sotho` | ZUL | D04 |

Это добавило девять первых и девять соседских событий: **511 + 618 → 520 + 627**. Сдвиги последующих D-назначений соответствуют порядку построения карты. Для всех девяти культур проверены n=1, назначенный D-тэг и сохранение прежнего MainCountry в `AdditionalCountrys`.

Существующее отдельное событие `setting_cores` с ID145002 выдаёт корки только нединамическому MainCountry и юниону. Поэтому его изменения требуют отдельного объяснения: исходные 145 культурных блоков после импорта стали 164, а после исправления девяти fallback — **155**. Итоговые эффекты для всех культур точно совпали с независимо восстановленными MainCountry и Union. Источник `simple_items.cpp` не изменён.

Помимо девяти перечисленных культур, выбор основного представителя изменился вследствие появления новых стран. Например, у `french`, `afro_antillean`, `bakongo`, `caribeno`, `polynesian` теперь основной представитель — D-тэг; событие145002 больше не выдаёт им прежние корки FRA/HAI/CNG/DOM/HAW. Для айнской культуры JAP заменён на AIN; для `fulbe`, `nguni`, `swahili` — SOK/ZUL/ZAN на GNE/MOZ/KNY. Это следствие существующего выбора MainCountry и разрешённой перегенерации. Возможности этих стран в новой системе первых и соседских корок проверены по полной карте и не зависят от сохранения старого эффекта145002.

## Идентификаторы, локализация и формат

Во всех шести изменённых CSV отсутствуют повторные ключи и непереведённые латинские значения после исключения игровых шаблонных переменных. Все использованные ключи `EVTNAME`, `EVTDESC` и опций разрешаются. Технические значения `0` и `1` в ранее существовавших скрытых событиях сохранены.

Полный поиск событий и решений не нашёл внешних скриптовых вызовов в перенумерованные группы. Перенумерация поэтому не перенаправляет существующий межфайловый вызов на другую страну. Проверка относится к статическим файлам; она не утверждает совместимость уже отложенного вызова или открытого окна из произвольного старого сохранения.

Окончательный набор содержит **21711 уникальных событий**, числовой список `events_id_list.txt` совпадает с этим множеством. Повторных ID, пропущенных записей списка и ссылок на отсутствующие события во всех `events`/`decisions` не найдено. Служебные строки заголовка списка не считаются идентификаторами.

Заголовок нового CSV импорта содержит разделители `;`, совместимые с чтением `autogen`; ранее выявленная потеря первого ключа ADR устранена. Устаревший комментарий в `adding_cores.h` исправлен: теперь он описывает MTTH `4*n` первых событий, фиксированный n и MTTH4 соседских. Реализация остаётся в `.cpp`. Ссылки из документов Chronology и `docs/autogen.md` проверены.
